# Glenn E-commerce Admin Panel

Sanity Content Studio for managing musical records and live events.

## Documentation

- **[Developer Documentation](./DEVELOPER.md)** - Setup, installation, and development guide
- **[User Guide](./USER_GUIDE.md)** - Complete guide for content editors and administrators

## Quick Start

### For Developers

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Deploy to Sanity hosting
npm run deploy
```

See [DEVELOPER.md](./DEVELOPER.md) for detailed setup instructions.

### For Content Editors

1. Receive an invitation email from Sanity
2. Create a Sanity account (if needed)
3. Accept the invitation
4. Access the admin panel at the provided URL
5. Start creating content!

See [USER_GUIDE.md](./USER_GUIDE.md) for complete user instructions.
